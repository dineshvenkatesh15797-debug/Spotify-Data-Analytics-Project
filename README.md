# Spotify Data Analytics Project

## Project Overview
Analysis of approximately 50,000 Spotify track records to explore music popularity, artist performance, genre trends, and streaming patterns.

## Tools Used
- **Excel:** Data cleaning and preparation
- **MySQL:** SQL queries, aggregations, ranking, and analytical views
- **Power BI:** Interactive dashboard and visualizations

## Business Questions
- Which genres have the most tracks?
- Which artists have the highest total streams?
- How do explicit and non-explicit tracks compare?
- Which genres have higher average popularity and danceability?
- Is track popularity associated with streaming volume?
- How do average streams vary by release month?
- Which artists have the largest track catalogues?

## Dashboard Pages
1. **Spotify Overview** — Key performance indicators, genre and artist comparisons.
2. **Track Analysis** — Explicit content, popularity, and danceability.
3. **Streaming Performance** — Popularity versus streams and release-month trends.
4. **Artist Insights** — Artist popularity and track catalogue size.

## Files
- `Spotify_Data_Analytics_Project.pbix` — Power BI report
- `Spotify_tracks SQL project.sql` — SQL analysis script
- `Spotify_Data_Analyst_Project.csv` — Dataset

## Project Goal
Use data analysis and visualization to explore track and artist performance and communicate findings clearly.

*Note: Interpretations and business recommendations should be validated against the dataset and analysis results.*
