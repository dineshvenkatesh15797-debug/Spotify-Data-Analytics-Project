# Spotify Data Analytics Project

## Project Overview
This project analyzes Spotify track data to identify patterns in track popularity, streaming performance, genres, and artists.

## Dataset
- Records: Approximately 50,000 tracks
- Data source: Spotify project CSV dataset

## Tools Used
- Microsoft Excel – Data cleaning
- MySQL – SQL queries and analysis
- Power BI – Interactive dashboards

## Key Analysis
- Total tracks, total streams, average popularity, and total artists
- Top genres by track count
- Top artists by total streams
- Explicit vs. non-explicit tracks
- Average popularity by genre
- Genre danceability comparison
- Track popularity vs. streams
- Average streams by release month
- Artist catalogue size and average popularity

## Business Objective
To explore track and artist performance patterns and generate insights that may help music streaming businesses understand their catalogue and audience engagement.

## Project Files
- `Spotify_Data_Analytics_Project.pbix` – Power BI dashboard
- `Spotify_Analysis.sql` – SQL analysis queries
- `Spotify_Cleaned.csv` – Cleaned dataset, if available

## Conclusion
The project uses data cleaning, SQL analysis, and Power BI visualizations to explore Spotify track performance and compare genres and artists.

*Note: Findings should be validated against the dataset before drawing business conclusions.*
